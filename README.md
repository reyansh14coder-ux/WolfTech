EduQuest - A game to level up your brain
EduQuest is a cutting-edge EdTech platform designed to transform learning into an engaging, cyber-themed role-playing game (RPG) experience. By gamifying educational tasks, we aim to maximize user engagement, focus, and knowledge retention.

Key features of the platform include:

Gamified Learning: Educational tasks are framed as "Quests" with XP and Coin rewards.

Focus Battle Arena: A Pomodoro-style timer/battle system where users "fight" an enemy to track focus time and earn rewards.

Skill Trees: Users level up skills like "Quantum Mathematics" and "Neural Programming" through mission completion.

AI Buddy: A simulated AI chat interface for motivation and information.
